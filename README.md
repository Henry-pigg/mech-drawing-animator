# 机械制图 · 分步绘制

上传一张题目照片，AI 把它拆成"可以逐步播放的绘图指令"，像老师板书一样一笔一笔画出来。
内置题库覆盖画法几何的常见题型；两者共用同一套 SVG 渲染器与国标线型。

## 两种模式

| 模式 | 输入 | 适用 |
|---|---|---|
| **AI 识图** | 手机拍的题目 / 截图 | 任意题型：三视图、表面取点、截交相贯、圆弧连接、零件图 |
| **内置题库** | 点选 | 20 个标准题型，几何由参数化引擎精确计算，参数可调 |

## 核心设计：图纸契约

AI 不画图，只输出一份**结构化的绘图指令**（DrawingDoc）。渲染器负责把它变成符合国标的图：

```json
{
  "meta": { "title": "支座三视图", "width": 920, "height": 660, "confidence": 0.88 },
  "warnings": ["俯视图左侧虚线判断为槽底"],
  "steps": [
    { "title": "画基准线", "narration": "先定三个视图的位置……",
      "primitives": [
        { "kind": "line", "lineType": "center", "x1": 160, "y1": 250, "x2": 300, "y2": 250 }
      ] }
  ]
}
```

图元白名单只有六种：`line` / `circle` / `arc` / `dimension` / `text` / `point`。
线型四种：`thick` 可见轮廓、`dashed` 不可见轮廓、`center` 中心线、`thin` 细实线。

**为什么这样设计**：让模型只负责"看懂 + 拆步骤"，不让它算箭头、尺寸界线、虚线间隔——这些交给渲染器，图才不会歪、不会抖。

## 渲染能力

- **国标线型**：GB/T 4457.4 四类线型，线宽、虚线间隔随图幅自动缩放。
- **尺寸标注引擎**：给两点 + 偏移量，自动算尺寸界线、箭头三角形、文字位姿（字头永远朝上）。
- **生长动画**：`pathLength` 归一化 + SVG mask，虚线也能一条一条画出来，不会整段闪现。
- **图框与标题栏**：自动排版，标题过长自动缩字号。
- **导出**：SVG（矢量）与 PNG（2×）。
- **容错**：模型返回的 JSON 会有围栏、错 id、超界坐标、非法半径——逐条修复并列出问题，不静默失败。

## 内置题库（20 题）

点线面投影 / 棱柱·棱锥·圆柱·圆锥·圆球三视图与表面取点 / 四棱柱截交 / 圆柱斜切 / 圆锥截交五情形 / 两圆柱正交相贯 / 叠加式·切割式组合体 / 正等测·斜二测 / 圆弧连接四形式 / 吊钩平面图形 / 阶梯轴·法兰盘·L 形支架。

这些题型的几何**不是手写坐标**：三视图由 3D 网格投影 + 隐藏线消除算出，圆弧连接由相切条件解圆心。

## 使用

1. 浏览器打开 `index.html`（或单文件版 `index-standalone.html`）
2. 点右上角 **⚙ 设置**，填 OpenAI 兼容的多模态接口（Base URL / Key / 模型）
3. 拖入或粘贴题目照片；也可以直接点左侧题库

> 若浏览器报 CORS，用 `python3 -m http.server 8080` 起本地服务再访问。
> Key 只存 localStorage，不上传。

快捷键：`←` `→` 切换步骤，空格播放/暂停。

## 项目结构

```
├── index.html / index-standalone.html
├── css/style.css
└── js/
    ├── config.js      API 配置
    ├── paper.js       2D 图纸模型（线/弧/圆/文字/尺寸标注）
    ├── geom3d.js      3D 网格、三视图投影、隐藏线消除、截切
    ├── views.js       三视图布局（长对正/高平齐/宽相等、45°线）
    ├── templates.js   画法几何题库
    ├── templates2d.js 几何作图 / 零件图题库
    ├── drawingdoc.js  图纸契约：归一化 + 转图元
    ├── render.js      SVG 渲染器（线型 / 标题栏 / 生长动画 / 导出）
    ├── player.js      分步回放
    ├── llm.js         系统提示词与识别调用
    └── app.js         界面
```

## 加题型

- **AI 路线**：不用改代码。提示词里已给出图元白名单与三视图布局规则，模型能画新题。
- **精确路线**：在 `templates.js` 里 `def(id, cat, name, prm => ({title, steps:[{title, desc, els}]}))`，`els` 用 `Paper.*` 构造；三视图可用 `Views.scene(meshes).outline('front')` 直接拿到带隐藏线的轮廓。
